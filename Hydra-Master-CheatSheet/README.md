## 📁 Wordlist Paths (Kali Linux Defaults)
Before running the commands, ensure you have your wordlists ready. I highly recommend installing SecLists: `sudo apt install seclists`

*   **Default Password List:** `/usr/share/wordlists/rockyou.txt` (Run `sudo gzip -d /usr/share/wordlists/rockyou.txt.gz` if it's not extracted).
*   **Default User List:** `/usr/share/wordlists/seclists/Usernames/top-usernames-shortlist.txt`
*   **Fast Password List:** `/usr/share/wordlists/fasttrack.txt` (Good for quick checks before deep brute-forcing).
